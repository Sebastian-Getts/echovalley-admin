# 旁白语音音色选择功能使用指南

## 功能说明

在题目管理页面的"旁白语音"页签，可以为旁白文本选择不同的 TTS 音色进行语音合成。

## 使用方法

1. 进入"题目管理"页面
2. 切换到"旁白语音"页签
3. 在"音色选择"下拉框中选择想要的音色
4. 点击对应题型条目的"生成"按钮
5. 等待生成完成后，点击"播放"试听

## 可用音色

### 中文音色
- **小云（女声）** - xiaoyun
- **小刚（男声）** - xiaogang
- **若兮（女声）** - ruoxi
- **思诚（男声）** - sicheng

### 英文音色
- **Abby（女声）** - Abby
- **小美（女声）** - xiaomei

## 功能特性

### 全局音色选择
- 音色选择器位于"旁白语音"页签顶部
- 选择的音色将应用于所有题型的旁白语音生成
- 支持实时切换音色

### 自动加载
- 页面加载时自动从服务器获取可用音色列表
- 如果服务器不可用，自动使用备用音色列表
- 默认选中第一个音色

### 错误处理
- 音色列表加载失败时显示备用列表
- 无效音色代码会返回明确的错误提示
- 网络错误时保持界面可用

## 注意事项

- 音色选择是临时的，刷新页面后会重置为默认音色
- 生成新的语音会覆盖之前的音频文件
- 每次生成都会调用 Aliyun TTS API，请注意使用量
- 音色代码区分大小写，建议使用小写

## 常见问题

### Q: 为什么我选择的音色没有保存？
A: 当前版本的音色选择是临时的，刷新页面后会重置。这是正常的设计行为。

### Q: 可以同时为不同题型设置不同音色吗？
A: 当前版本使用全局音色设置，所有题型共用同一个音色。未来版本可能支持为每个题型单独设置音色。

### Q: 生成语音时提示"音色无效"怎么办？
A: 请确保选择的音色代码在可用列表中。如果问题持续存在，可能是服务器配置问题，请联系管理员。

### Q: 为什么有时候音色列表显示的是备用列表？
A: 当无法从服务器获取音色列表时（网络问题或服务器错误），系统会自动使用内置的备用列表来保证功能可用。

## 技术信息

### API 端点
- **获取音色列表**: `GET /api/v1/tts/voices`
- **生成旁白语音**: `POST /api/v1/question-types/{id}/preface-items/{index}/synthesize`

### 请求示例
```bash
# 获取可用音色
curl http://localhost:8000/api/v1/tts/voices

# 使用指定音色生成语音
curl -X POST http://localhost:8000/api/v1/question-types/1/preface-items/0/synthesize \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"voice": "xiaoyun"}'
```
